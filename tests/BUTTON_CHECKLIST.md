# 示範區逐步按鍵檢查

檢查日期：2026-10-04。對應 `test_buttons.py` 的逐鍵矩陣，以及 `test_workflow.py` 的完整流程測試。

本次結果：`python3 -m unittest discover -s tests -v` 全部 13 組測試通過（102.868 秒）；未出現未捕捉的瀏覽器 JavaScript 錯誤。

## 檢查方式

- 手動作業 9 步、人機協作 5 步，連同開始選單、檔案對話框、右鍵選單、報表及檢核視窗，共 53 個畫面狀態。
- 逐鍵矩陣在 1366 × 768、390 × 664 各跑一次，共檢查 1,036 個按鈕出現位置：682 個實際點擊並驗證結果、170 個驗證應為停用、184 個因選單／對話框遮住而在對應的未遮擋畫面測試。這是跨畫面重複計數，不是 1,036 種不同功能。
- 每個啟用按鈕都必須有明確的結果斷言；新增但沒有驗證規則的按鈕會使測試失敗。放大、收起與關閉後另行點擊還原，確認步驟沒有改變。
- 個別畫面以隔離狀態測試各按鈕；另外從第一步實際走完流程，避免只測得出孤立畫面正常。

## 手動作業

| 步驟 | 已檢查的操作與條件 |
| --- | --- |
| 1 登入照管平台 | 示範登入、進入資料匯出。 |
| 2 匯出照會資料 | 查詢、匯出 XML、進入下載資料夾。 |
| 3 確認下載檔案 | 檔案選取、下載／文件切換、上一頁／下一頁及歷程邊界、搜尋與無結果後重試；Windows 開始選單開關、Excel／檔案總管按鈕、開始選單搜尋、Enter 啟動 Excel。 |
| 4 以 XML 表格匯入 | Excel 首頁／開啟／返回活頁簿／空白活頁簿；瀏覽、資料夾切換、選取 XML、開啟、取消與關閉；三種匯入選項、錯誤選項後改選重試、XML 列 Enter 開啟與匯入確認。 |
| 5 檢視資料並另存 | 檔案、首頁、開啟、另存新檔、返回活頁簿、瀏覽；檔名、位置、儲存類型、儲存／取消／關閉；錯誤類型及無效檔名後重試、保留取消前輸入、自訂檔名、Enter 存檔。匯入後的「空白活頁簿」明確停用，避免誤返回原資料卻被當成新檔。 |
| 6 建立樞紐分析表 | 四個欄位的全部 16 種勾選組合；完整勾選才可建立，漏勾時留在原步驟並顯示提示。 |
| 7 篩選碼別與填表 | BA／BB／DA × 全部／已接案共 6 個篩選組合，核對顯示數值；樞紐分析表／輪派報表切換、填表內容保留、錯誤數字後重試、完成填表前進。 |
| 8 核對格式與數字 | 三項檢核的全部 8 種組合；全部勾選才可儲存。切換流程再回來仍保留勾選。 |
| 9 儲存完成 | 檔案選取與資料夾導航；報表和原始資料活頁簿皆以雙擊／Enter 開啟、返回資料夾；切換至 Skill，包含視窗放大時的完成按鈕。 |

## 人機協作

| 步驟 | 已檢查的操作與條件 |
| --- | --- |
| 1 放入 XML | 檔案／Input 資料夾選取、開啟資料夾、下載／工作區／Input 切換、上一頁／下一頁／上一層、剪下／貼上／復原；右鍵選單各操作、搜尋、拖曳、鍵盤操作。未移入前 OpenClaw 停用，移入後可由 Windows 工作列點入，檔案總管收起時也可操作。 |
| 2 執行 Skill | `/sas` 建議選項、選取、清除與重新選取、輸入「執行」後送出；未符合條件時送出停用；展開／收合說明。 |
| 3 決定新單位 | 加入、全部忽略、錯誤編號後重試；兩個有效分支皆走完整流程；展開／收合明細。 |
| 4 Excel 檢核與歸檔 | 開啟／關閉檢核、三項檢核全部 8 種組合、完成檢核；未完成前不可歸檔，取消已勾項目後重新鎖定；錯誤確認文字後重試，合法確認文字前進；確認草稿保留、明細展開／收合、檢核視窗焦點循環及 Escape。 |
| 5 完成 | 完成狀態、執行紀錄與工作區明細展開／收合、返回手動作業。 |

## 共用控制與非示範區

- 逐鍵矩陣包括每個畫面的視窗收起、放大、關閉與還原；完整流程另外測試跨步驟保留放大狀態。
- 既有完整測試覆蓋桌機、平板、手機直向、手機橫向及 320px 窄螢幕，包含觸控模擬與短螢幕。
- 非示範區覆蓋流程卡片、固定切換列、跳轉連結、重設確認／取消、專注模式、工具提示、全螢幕成功／拒絕、鍵盤操作及減少動態效果偏好。

## 範圍與重跑

這是教學模擬，不包含 Windows／Excel 的全部功能。畫面上的停用按鈕（例如不在練習範圍內的新增、複製）會驗證停用狀態；不將它們列為已實作功能。選單中的裝飾文字不是可操作按鈕。

以上驗證使用 Chromium。不同尺寸及觸控為瀏覽器模擬，尚未在實機 Safari／Firefox 驗證；測試也不會操作真實 XML 或 Excel 檔案。逐鍵矩陣是列出的 53 個代表性狀態，並非任意輸入與任意操作順序的數學窮舉。

執行方式見 [README.md](README.md)。如需輸出逐筆結果：

```sh
SAS_BUTTON_AUDIT_JSON=/tmp/sas-button-audit.json python3 -m unittest discover -s tests -v
```
